# Capstone Judging App Setup Guide

My capstone project is the ASU Capstone Judging App. It helps manage capstone showcase judging, including project groups, rubrics, scores, and results. The project includes a PHP website, Android and iOS applications, and a Go API for the mobile applications.

Development tools include VS Code, Docker for the website, Xcode for iOS, and Android Studio for Android. Git and GitHub help the team track changes and collaborate.

For this Git practice repository, I cloned the repository onto my Mac and created a separate branch named docs/setup-guide. I am using this branch to practice documenting changes, creating commits, and opening a pull request before merging into main.
